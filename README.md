# Class to Court

Create a mobile-first, single-page landing site for a student concept: an SEO page for Mokobara, an Indian bag and travel brand (tagline: "The Joy Is in the Details"). Theme: "From class to court in one bag." Target keyword: "laptop backpack for college".

Set in index.html:

- Title: Best Laptop Backpack for College (2026) | Mokobara

- Meta description: Fits a 16" laptop, survives the commute, expands for the weekend. Find the Mokobara backpack that fits your college day. Take the 30-second quiz.

Page structure (exactly one H1, every section gets an H2):

1. Hero: H1 "The Best Laptop Backpack for College, From Class to Court", a one-line subhead, and a "Take the quiz" button that scrolls to the quiz.

2. H2 "Which Mokobara fits your college day?" with 3 product cards (H3s) for Overnighter Backpack, Backpack 16L and Em Travel Backpack 32L. Leave the card text as placeholders for now. No prices.

3. H2 "Quiz: Which Mokobara fits your plan?" Leave it as an empty placeholder section; I'll add the quiz next.

4. H2 "What should I carry to my first padel game?" with a highlighted answer box (placeholder text).

5. H2 "FAQ" with an accordion of 6 placeholder questions as H3s.

6. Footer: "Student concept for a Schbang x Atlas SkillTech brief. Not affiliated with or commissioned by Mokobara or 7Padel."

Design: clean, premium, Gen Z. Off-white background, black text, one warm accent colour, rounded cards, generous spacing, big tap targets. It must look great on a 390px phone screen. No stock photos of people; use simple icons.
